# CS4127_LCB6796
For my assignment, I was asked to create a website and then include the progress of how I made it into this report that I am currently writing. I will be introducing the project scenario, the aim of my website as well as who is the target audience for this. The project scenario for this assignment is that I, a web developer was approached by one of the staffs at the Ministry of Tourism in Brunei Darussalam to design and build a website. The aim behind the website is to promote Brunei as a travel destination as well as for visitors to plan their trip. The tourism website needs to showcase the best of Brunei to both local and international audience and most importantly, the website should inform and inspire potential visitors.
